# NSNightreign-releases

個人用アプリ NSNightreign の、**更新ファイルの置き場**です。アプリが自分を更新するときに、ここの [Release](../../releases/latest) を見に来ます。

ほかの人に使ってもらうために公開しているものではありません。動作の保証・質問への対応・要望の反映はしません。

## 更新の仕組み
- 新しい版を置くと、入れてあるアプリの右上に「v○ に更新」が出ます。押すと落として入れ替え、起動し直します（所持遺物や設定は残ります）
- 添付の `NSNightreign-setup.exe` は、アプリがこの名前で探します
- 初めて入れるとき、または更新の機能が無い古い版からは、`NSNightreign-setup.exe` を手で実行します（Windows 用）

## 中身について
- ELDEN RING NIGHTREIGN の遺物を管理する、非公式の個人制作のツールです。ゲームの開発元・販売元とは関係ありません
- 白面の人の「RelicHub」（[@hakumenkyo](https://www.youtube.com/@hakumenkyo)）を参考に作成しました
- ゲームのデータと地図の画像は、神攻略の[ナイトレイン攻略wiki](https://kamikouryaku.net/nightreign_eldenring/)を参照しています
