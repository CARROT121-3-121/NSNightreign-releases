# NSNightreign

**ELDEN RING NIGHTREIGN の遺物を、読み取って、探して、組み合わせる。**

非公式の個人制作のツールです。ゲームの開発元・販売元とは関係ありません。

## できること
- **遺物を読み取る**：ゲーム画面、または録画した動画から、遺物の一覧を OCR で取り込みます（日本語・英語の画面）
- **所持遺物を探す**：効果・色などで絞り込み、タグを付け、ビルドごとの評価点を見られます
- **器で試す**：キャラクターの器に遺物を入れ、効果の合計・ステータス・ダメージ補正を確かめ、プリセットに残せます
- **組み合わせを探す**：持っている遺物から、ダメージやビルドの評価点が高い組み合わせを探します
- **図鑑・Tips**：武器・戦技・魔術/祈祷・アイテム・遺物効果・付帯効果と、地変の地図つきまとめ
- **スマホから開く**：Tailscale を使い、PC で動いているアプリをスマホのブラウザから使えます（任意）

## 入れ方
1. [最新版](../../releases/latest)から `NSNightreign-setup.exe` を落として実行します
2. 署名が無いため、Windows の警告が出ることがあります。「詳細情報」→「実行」で進めます

管理者の権限は要りません。入れる先は `%LOCALAPPDATA%\Programs\NSNightreign` です。

## 更新
新しい版が出ると、アプリの右上に「v○ に更新」が出ます。押すと落として入れ替え、起動し直します。所持遺物や設定は残ります。

v0.1.0 より前のインストーラーで入れた版には更新の機能が無いので、一度だけ手で上書きしてください。

## うまく動かないとき
設定タブの「ファイルをコピー」で記録をコピーできます。記録には、読み取った遺物やファイルの場所が含まれることがあります。
